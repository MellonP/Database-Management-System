# Library Management System (MySQL)

## Description

**library_management_system** is a MySQL-based relational database designed to manage all core aspects of a real-world library. It supports:

- Managing books, authors, publishers, and categories
- Tracking members and their loans, reservations, and fines
- Maintaining data integrity through foreign keys and constraints

The system demonstrates normalized design, clear entity relationships, and realistic data interactions between members and the library’s resources.
